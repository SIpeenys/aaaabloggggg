## 🚀 更新博客（连接 GitHub 后）

现在腾讯云已经连上了你的 GitHub 仓库，更新流程更简单了：

### 第 1 步：在 VSCode 中修改文件

- 改个人简介 → 编辑 `about.html`
- 加新文章 → 编辑 `data.js`

### 第 2 步：提交到 GitHub（让网站自动更新）

在 VSCode 里操作（不需要命令行）：

1. 点击左侧的 **「源代码管理」** 图标（三个圆点连线那个）
2. 你会看到修改过的文件列表
3. 在输入框里写一句说明（比如 "添加新文章"）
4. 点击 **✓ 提交（Commit）**
5. 点击 **「同步更改」** 或 **「推送（Push）」**

> 或者按键盘快捷键：Ctrl + Shift + G 打开源代码管理

### 第 3 步：等待自动部署

推送到 GitHub 后，腾讯云会自动检测到更新，自动部署网站。等 1-2 分钟刷新页面就能看到效果。

## ✍️ 场景二：添加一篇新文章

打开 `D:\vscode_file\blog\data.js` 进行编辑。

### ⚠️ 重要：JS 里怎么写 HTML？

文章内容使用 **反引号（`` ` ``）** 包裹。反引号里面可以直接写 HTML，**想换行就换行**。

**反引号在哪？** 键盘左上角，ESC 键下面，数字 1 左边那个键 \`

```js
content: `
    <h2>标题</h2>
    <p>段落内容，想换行直接回车就行</p>
`
```

### 添加新文章的操作步骤

**第 1 步：** 打开 `data.js`，滚动到文件最末尾

**第 2 步：** 找到文件末尾，它长这样：
```js
            `              // 文章内容结束
        }                  // ← 最后一个 } （文章结束）
    ]                      // 数组结束
};                         // 整体结束
```

**第 3 步：** 在最后一个 `}` 后面加一个**逗号**，然后**按回车换行**，粘贴新文章：

最终效果：
```js
            `              // 旧文章内容结束
        },                 // ⭐ 原来 } 改成 },  （加逗号！）
        {                  // ⭐ 新文章开始（新的一行）
            id: 8,                // id = 目前最大的数字 +1
            title: '你的文章标题',
            category: '文章分类',
            author: '博主',
            date: '2026-06-12',
            readTime: '3 分钟',
            image: 'https://images.unsplash.com/图片ID?w=800&h=400&fit=crop',
            excerpt: '首页卡片上显示的文章简介',
            content: `            // ⭐ 注意这里是反引号 `
                <h2>第一章</h2>
                <p>这里写文章内容，直接写 HTML。</p>
            `                        // ⭐ 结尾也是反引号
        }                            // 新文章结束，不用加逗号
    ]                                // 这一行原来就有，不要动！
};
```

### 常用 HTML 标签（文章内容里用）

| 效果 | 写法 |
|------|------|
| 标题 | `<h2>标题文字</h2>` |
| 段落 | `<p>文字内容</p>` |
| 加粗 | `<strong>加粗文字</strong>` |
| 图片 | `<img src="图片链接" alt="描述">` |
| 代码 | `<pre><code>代码内容</code></pre>` |
| 引用 | `<blockquote>引用文字</blockquote>` |
| 链接 | `<a href="https://xxx.com" target="_blank">链接文字</a>` |
| 列表 | `<ul><li>项目1</li><li>项目2</li></ul>` |

## 📌 常见问题

### Q：GitHub 推送不上去？
可能是网络问题。可以换用**打包 zip 上传**的方式：
- 右键 `blog` 文件夹 → 压缩成 zip
- 打开 https://console.tencentcloud.com/edgeone/pages
- 找到项目 → 上传部署

### Q：文章图片不显示了怎么办？
图片链接可能失效了。去 https://unsplash.com/ 重新找一张图替换即可。

### Q：id 写重复了会怎样？
首页会显示不正常。每篇文章的 `id` 必须是唯一的数字，新建时看一眼最大的 id 是多少，+1 即可。

### Q：留言板的留言存在哪里？
存在 Supabase 数据库里。登录 https://supabase.com/ → 左侧 Table Editor → 可以看到 `messages` 表。
