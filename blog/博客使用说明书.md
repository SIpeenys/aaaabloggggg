## ✍️ 场景二：添加一篇新文章

打开 `D:\vscode_file\blog\data.js`，拉到文件末尾，在最后一个 `}` 后面添加新文章。

### 示例：添加一篇文章

原始文件末尾大概长这样：
```js
        // ... 前面有很多文章 ...
        {
            id: 2,
            title: '第二篇文章标题',
            // ... 其他字段
        }
    ]
};
```

在倒数第三个 `}` 和 `]` 之间加一个逗号，然后插入新文章：

```js
        // ... 前面的文章 ...

        {
            id: 2,
            title: '第二篇文章标题',
            // ...
        },
        // ⭐ 在上面这行的逗号后面，粘贴下面这段新文章 ⭐
        {
            id: 3,                // id 填目前最大的数字 +1
            title: '你的文章标题',
            category: '文章分类',
            author: '博主',
            date: '2026-06-11',   // 写今天的日期
            readTime: '3 分钟',    // 预估阅读时间
            image: 'https://images.unsplash.com/图片ID?w=800&h=400&fit=crop',
            excerpt: '这里写文章简介，会显示在首页卡片上',
            content: `
                <h2>第一章</h2>
                <p>文章内容，支持 HTML 语法。</p>

                <h2>第二章</h2>
                <p>可以插入图片：</p>
                <img src="https://图片地址.jpg" alt="描述文字">

                <p>可以插入代码：</p>
                <pre><code>console.log("Hello World");</code></pre>

                <p>可以引用：</p>
                <blockquote>这是一段引用文字</blockquote>
            `
        }
    ]
};
```

### 常用 HTML 标签（文章内容里用）

| 效果 | 写法 |
|------|------|
| 标题 | `<h2>标题文字</h2>` |
| 段落 | `<p>文字内容</p>` |
| 加粗 | `<strong>加粗文字</strong>` |
| 图片 | `<img src="图片链接" alt="描述">` |
| 代码 | `<pre><code>代码内容</code></pre>` |
| 引用 | `<blockquote>引用文字</blockquote>` |
| 链接 | `<a href="https://xxx.com" target="_blank">链接文字</a>` |
| 列表 | `<ul><li>项目1</li><li>项目2</li></ul>` |

### 图片去哪里找？

推荐免费图库：https://unsplash.com/

选好图片后点击图片 → 右下角复制链接，格式类似：
```
https://images.unsplash.com/photo-xxxxx?w=800&h=400&fit=crop
```

## 🚀 场景三：部署更新到腾讯云

修改完文件后，按以下步骤操作：

   ```

   ```

2. **打包成 zip**
   - 在 `blog` 文件夹上右键 → 「发送到」 → 「压缩(zipped)文件夹」

4. **刷新网站查看效果**

## 📌 常见问题

### Q：博客文章图片不显示了怎么办？
图片链接可能失效了。去 https://unsplash.com/ 重新找一张图，替换 `image` 字段的链接。

### Q：id 写重复了会怎样？
首页会显示不正常。每篇文章的 `id` 必须是唯一的数字，新建时看一眼最大的 id 是多少，+1 即可。

### Q：写错了想回退怎么办？
腾讯云 EdgeOne 控制台可以查看历史部署版本，选择上一个版本重新部署即可。

### Q：留言板的留言存在哪里？
存在你注册的 Supabase 数据库里。登录 https://supabase.com/ → 左侧 Table Editor → 可以看到 `messages` 表里的所有留言数据。
